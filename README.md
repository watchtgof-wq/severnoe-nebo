# Северное небо

Учебный интерактивный путеводитель для первых наблюдений за звёздным небом. Проект выполнен на чистых HTML, CSS и JavaScript без фреймворков и сервера.

## Демо

[Открыть опубликованный сайт](https://watchtgof-wq.github.io/severnoe-nebo/)

## Страницы

- `index.html` — главная страница, слайдер, атлас объектов, поиск и фильтры;
- `auth.html` — регистрация и вход с валидацией;
- `cabinet.html` — защищённый личный кабинет и избранные объекты.

## Реализовано

- семантическая адаптивная вёрстка для компьютера, планшета и телефона;
- липкая шапка и мобильное бургер-меню;
- слайдер из четырёх экранов: стрелки, точки, автопрокрутка и пауза;
- восемь карточек, которые генерируются из JavaScript-массива;
- поиск и фильтрация по категориям;
- модальные окна с подробной информацией;
- избранное с сохранением в `localStorage`;
- регистрация, вход, выход и проверка доступа к кабинету;
- светлая и тёмная темы;
- форма подписки с валидацией;
- доступные подписи, состояния фокуса и поддержка `prefers-reduced-motion`.

## Как запустить локально

Можно открыть `index.html` напрямую или запустить статический сервер из папки проекта:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Технологии

- HTML5;
- CSS3: переменные, Grid, Flexbox, адаптивные медиазапросы;
- JavaScript ES6+;
- Web Storage API (`localStorage`);
- Intersection Observer API;
- нативный элемент `dialog`.

## Важно

Авторизация является учебной имитацией: данные хранятся только в `localStorage` текущего браузера. Для настоящего проекта потребовались бы сервер, база данных, безопасное хеширование паролей и защищённые сессии.
